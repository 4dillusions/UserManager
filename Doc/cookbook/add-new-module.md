# Add a New Module

[🇭🇺 Magyar változat](add-new-module_HU.md) · [🇬🇧 Cookbook](README.md) · [🇬🇧 Architecture handbook](../architecture.md)

Create a module only when there is a real ownership or boundary reason. Give the module a narrow registration entry point, keep dependencies aligned with the architecture, and integrate it from WPFUI. Do not create a module just to make a small folder look symmetrical. Add tests for behavior and dependency registration.
